# snake.exe-1.3
A browser-based Snake game developed as a personal portfolio project to practice and improve programming skills, explore web development, and experiment with interactive features.
**Play now:** [[Insert your game link]](https://claramirandavie.github.io/snake.exe-1.3/)

## Features
- **5 Difficulty Levels:** Easy, Normal, Hard, Insane, and Extreme, each with different gameplay speeds.
- **Dual Controls:** Move the snake using either the arrow keys or WASD.
- **Pause Menu:** Pause the game and access Resume, Restart, and Main Menu options.
- **Custom Skins:** Customize the snake's appearance with different skins.
- **Music:** Background music and audio customization.
- **Game Statistics:** Track gameplay performance and personal records.
- **Timer:** Keep track of the time spent in each session.
- **Score System:** Earn points by collecting food and track your progress.
- **Responsive Interface:** Designed for an interactive browser-based experience.

## Controls
| Key | Action |
|---|---|
| ↑ / W | Move Up |
| ↓ / S | Move Down |
| ← / A | Move Left |
| → / D | Move Right |
| Esc / P | Pause / Resume |

## Project Purpose
This project was created to apply programming concepts in practice, particularly JavaScript logic, DOM manipulation, event handling, game mechanics, and interface development.
It is an ongoing personal project, with new features and improvements being developed over time.
